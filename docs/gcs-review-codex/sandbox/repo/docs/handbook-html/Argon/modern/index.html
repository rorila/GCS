Teil A: „Mein erster interaktiver Baum“

15 Kapitel · Einsteiger-Tutorial (Kapitel 1–15)

Ein Setzling steht auf einer Wiese. Per Knopfdruck gießt man ihn — bei genug Wasser wächst er in Stufen. Ein Timer lässt den Wasservorrat wieder sinken. Du lernst den kompletten GCS-Arbeitsplatz, Variablen, Tasks, Actions, Bedingungen, den Flow-Editor, Spritesheets und den ZIP-Export kennen.

🌳

Teil B: „Der wachsende Baum“

8 Kapitel · Pädagogische Lernwelt (Kapitel B1–B8)

Das Kind beantwortet Mathematik-Aufgaben. Richtige Antworten erhöhen die Variable RichtigeAntworten und lösen automatisch Reaktionen in der Spielwelt aus: Der Baum wächst, ein Baumhaus entsteht, Deko-Sprites werden per Drag-&-Drop platziert und Zufallsaufgaben entstehen automatisch.

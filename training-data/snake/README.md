# Snake-Training

`snake-gesamt.jsonl` enthält 12 kurze Beispiele für die tatsächliche GCS-AgentController-API. Im Training-Tab Datei auswählen, Beispiele öffnen und prüfen, freigeben und separate Fragen aus `pruefauftraege.txt` eintragen. Zunächst wenige Schritte wählen. Es wurde noch kein Training gestartet.

Die Beispiele vermitteln einzelne Operationen, kein vollständiges Snake-Spiel. Eine erfolgreiche Laufzeitprüfung des Spiels garantiert keine korrekte Ausgabe des trainierten Modells. Antworten anhand echter API und Ausführung bewerten; bisherige Fähigkeiten ebenfalls prüfen. Der konfigurierte Startadapter wird verwendet, nicht automatisch der zuletzt trainierte Adapter.

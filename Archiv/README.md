Server oder den Tests referenziert. Aktive Projekte liegen in
`game-server/public/projects/`, CMS-Code in `scripts/cms/`.

| `oneoffs/` | abgearbeitete Einmal-Migrationen aus dem Repo-Root |
| `logs/` | alte Test-/Server-Logs, `test_write2.txt` |
| `demos/` | Demo-Builder-Projekte (MatheQuiz, RaketenCountdown, Retro Tennis, Tutor …) |
